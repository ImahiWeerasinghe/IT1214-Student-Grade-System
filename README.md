# IT1214-Student-Grade-System

## Project Purpose

This project is a Java console-based application developed to manage student academic records.

The system allows teachers to:

- Add student records
- Display all students
- Search students by ID
- Calculate average marks

## Technologies Used

- Java
- OOP Concepts
- GitHub Version Control

## How to Run

1. Compile the Java files

javac Student.java StudentGradeSystem.java

2. Run the program

java StudentGradeSystem

## Features

- Add Student
- Display All Students
- Search Student by ID
- Calculate Average Marks
